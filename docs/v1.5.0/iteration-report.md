# PAE v1.5.0 第一轮迭代报告

## 1. 版本目标

v1.5.0 的目标不是重复建设 v1.4.0 平台知识目录，而是把真实产品资料转化为可审核、可追溯的平台知识候选，再复用既有人工晋升闭环。

## 2. 第一轮完成范围

| 范围 | 状态 | 说明 |
|---|---|---|
| 产品资料目录 | 完成 | 类型、产品、版本、敏感级别、文件名、存储位置及 SHA-256 指纹 |
| 敏感资料门禁 | 完成 | internal/confidential 自动标记不得进入公开测试夹具 |
| 文本资料解析 | 完成 | Markdown、TXT、JSON |
| Office 资料解析 | 完成 | DOCX 正文/页眉页脚；PPTX 幻灯片正文 |
| Axure RP 边界 | 完成 | 不进行猜测性解析，要求 HTML 导出包或人工补充 |
| 知识候选 | 完成 | Capability、Pattern、Component、Constraint 草稿及原文证据 |
| 正式知识比较 | 完成 | 重复、补充、新增和待判断，只读且保留人工门禁 |
| CLI | 完成 | material add/list/extract/derive/compare |
| 自动化验证 | 完成 | 新增 7/7；全量 281/281 |

## 3. 安全边界

- 候选状态固定为 `draft`，报告状态固定为 `pending-product-manager-review`。
- 资料解析和比较不会写入 `knowledge/platform`。
- 正式知识仍只能通过 v1.4.0 的人工审核和显式接受流程晋升。
- 原始公司资料不进入仓库公开示例和自动化夹具。
- Axure RP 无法可靠解析时明确失败降级，不构造虚假页面或交互。

## 4. 后续迭代

1. 增加 Axure HTML 导出包页面层级、文本与基础交互解析。
2. 将规则式候选提取升级为可替换的 LLM 提取器，并保持结构校验和原文证据门禁。
3. 增加版本变化、内容冲突和来源补充的细粒度比较。
4. 将审核决定转换为 v1.4.0 可接受的正式候选包。
5. 使用脱敏的基础平台组织机构资料完成真实验收。

## 5. 当前结论

第一轮代码与自动化基线通过，版本仍处于开发分支，不代表 v1.5.0 已正式发布。MasterGo 真实画布继续作为独立人工验收项。
