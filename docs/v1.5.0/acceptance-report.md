## 3. 安全与人工门禁

- internal和confidential资料不得进入公开测试夹具。
- Axure RP专有内容不进行猜测性解析。
- LLM候选证据必须逐字存在于指定来源章节。
- 候选不会自动进入正式知识目录。
- `merge-source`和`create-version`当前仅记录审核决定，不执行隐式历史覆盖。
- 正式知识写入必须显式执行，并在写入前验证目录版本、候选ID和完整目录关系。
