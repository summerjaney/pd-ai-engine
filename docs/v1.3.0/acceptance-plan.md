# PAE v1.3.0 验收计划

## 1. 验收目标

验证 PAE 能否使用一项脱敏的真实低代码平台需求，完成从多来源材料输入到开发评审的产品设计闭环，并确保 v1.2.0 能力保持兼容。

## 2. 验收场景

场景：表单设计器“发布前校验规则”。该需求涉及已有平台能力增强、存量表单兼容、设计态错误定位和发布阻断规则，适合验证平台与项目边界及跨成果物一致性。

## 3. 验收用例

| 用例 | 验收内容 | 预期结果 |
|---|---|---|
| TC-130-001 | 五节点状态汇总 | 正确识别当前节点与确认进度 |
| TC-130-002 | 成果物变化 | 原确认自动失效 |
| TC-130-003 | 多来源登记 | 生成安全、可追溯来源索引 |
| TC-130-004 | 重复与敏感来源 | 拒绝重复，支持排除分析 |
| TC-130-005 | 原始需求修订 | 自动更新来源指纹 |
| TC-130-006 | 机密资料误纳入分析 | 统一检查判定为阻断 |
| TC-130-007 | 既有验证结果聚合 | 正确映射四级问题 |
| TC-130-008 | 真实低代码需求闭环 | 五节点全部确认，设计检查 PASS |

## 4. 发布门槛

- v1.3.0 新增用例全部通过。
- v1.2.0 及历史自动化测试无回归。
- 跨成果物设计检查无 BLOCKER 和 IMPORTANT。
- MasterGo 实际画布验收独立记录；未完成时不得宣称真实画布 PASS。
- 公共仓库不得包含真实公司、客户或个人敏感资料。
