# PAE v0.8.0 迭代计划

## 版本主题

产品文档自动交付：在 v0.7.0 的需求、页面规划、多页面原型、MasterGo、PRD 与验收链路之后，生成产品手册、操作手册、追踪矩阵和完整交付包。

## 第一批：手册生成基础

- 建立产品手册、操作手册和追踪矩阵的 `0.8` 数据契约。
- 新增 `pae manual generate <需求目录>`。
- 从 Prototype DSL、PRD 与需求元数据生成 Markdown 和 JSON 双格式手册。
- 操作步骤只引用真实页面、操作、角色和跳转。
- 建立来源到手册章节、操作路径的追踪关系。

## 后续批次

1. 页面、角色、操作路径和规则一致性检查（已完成）。
2. 修订影响分析与手工内容保护（已完成）。
3. 完整交付清单和正式验收扩展。
4. 基础平台“组织结构管理”真实需求验收。

## 本版本不包含

Word/PDF 复杂版式、MasterGo 截图、多语言、在线文档发布、企业知识库/RAG、多 Agent 和可视化手册编辑器。
