### 4.2 真实 JSON 结构（基于实测产物）

实测产物路径：`/tmp/pae-fourth-batch/tc047/hr-system/requirements/REQ-001-leave-request/07-mastergo/mastergo-result.json`

```json
{
  "schemaVersion": "0.2",
  "createdPages": [
    { "pageId": "申请列表", "pageName": "申请列表", "nodeId": "mg-申请列表" }
    // ... 6 个页面
  ],
  "createdAt": "2026-07-27T05:45:22.414Z",
  "status": "pending"
}
```

类型定义（src/domain/types.ts:134-148）：

```typescript
export interface MasterGoResult {
  schemaVersion: "0.2";
  fileId?: string;
  pageId?: string;
  nodeId?: string;
  createdPages: Array<{ pageId: string; pageName: string; nodeId: string }>;
  createdAt: string;
  status: "pending" | "confirmed" | "rejected";
  confirmedAt?: string;
  confirmedBy?: string;
}
```

### 4.3 字段支持情况

| 字段 | 是否支持 | 取值范围 | 说明 |
|---|---|---|---|
| `status` | ✅ 支持 | `pending` / `confirmed` / `rejected` | 人工填写，不支持 success/failed/partial |
| `createdPages` | ✅ 支持 | 数组 | 记录已创建的页面 ID/名称/节点 ID |
| `createdAt` | ✅ 支持 | ISO 8601 | 创建时间 |
| `fileId` | ✅ 可选 | 字符串 | MasterGo 文件 ID（可选） |
| `pageId`、`nodeId` | ✅ 可选 | 字符串 | 当前页面/节点 ID |
| `errorMessage` | ❌ 不支持 | — | 字段不存在 |
| `success` / `failed` / `partial` | ❌ 不支持 | — | status 字段不支持这些值 |

### 4.4 MasterGo MCP 实际能力

| 能力 | 是否支持 | 证据 |
|---|---|---|
| MCP 直接消费 mastergo-data.json | **否**（当前 MasterGo MCP 画布提交接口均不接受 mastergo-data.json） | 工具 schema 核查确认 |
| MCP 创建画布 | **已确认支持**。`submit_page_to_canvas` 可通过 HTML 文件创建画布；但调用成功不等于画布内容完整，实际结果仍需人工核查 | 工具 schema 核查确认 + TC-052/053/055 实际执行验证 |
| MCP 回写 mastergo-result.json | **否**（无代码支持） | grep 整个 src/ 无 MasterGo MCP 写入引用 |
| 失败状态记录 | **否**（字段不存在） | types.ts 无 errorMessage 字段 |
| 失败原因记录 | **否**（字段不存在） | types.ts 无 errorMessage 字段 |

### 4.5 能力缺口与登记

| 缺口 | 类型 | 编号 | 状态 |
|---|---|---|---|
| mastergo-result.json 不支持 success/failed/partial 状态 | **v0.3.0 当前能力边界/后续增强项** | — | 已知能力边界，登记为后续增强项；非 PAE-030 缺陷；不作为第五批执行阻断项 |
| mastergo-result.json 不支持 errorMessage 失败原因字段 | **v0.3.0 当前能力边界/后续增强项** | — | 已知能力边界，登记为后续增强项；非 PAE-030 缺陷；不作为第五批执行阻断项 |
| MasterGo MCP 不具备回写 mastergo-result.json 能力 | **v0.3.0 当前能力边界/后续增强项** | — | 已知能力边界，登记为后续增强项；非 PAE-030 缺陷；不作为第五批执行阻断项 |
| 现有自动化测试覆盖 W-13、L-06 仅检查文件存在 | 覆盖不足 | 已有部分覆盖 | — |

> **重要**：
> - 上述三项能力缺口当前不构成 PAE 缺陷，仅作为 v0.3.0 已知能力边界登记，列入后续增强项；

> - 只有在现有产品需求、README、接口约定或 v0.3.0 规格中明确承诺了自动回写能力，才能重新登记为产品缺陷；
