## 六、归档操作指引（历史参考）

用户归档截图时，请按以下步骤操作：

1. 将原始 PNG 截图复制到 `docs/testing/evidence/fifth-batch/` 目录；
2. 按本清单序号 1-9 的文件名命名；
3. 如 TC-054-R 两张聚焦截图尚未单独裁切，可从原始全屏截图裁切后保存；
4. 不得使用临时占位图片、空文件、重复图片或伪造截图填充；
5. 一张截图不得冒充多个不同证据，除非截图内容确实同时完整覆盖多个证据要求，并在本清单中明确说明；
6. 归档后通知 Agent 执行校验（文件大小、PNG 文件头、内容核查）；
7. 校验通过后由 Agent 更新本清单和验收报告中的归档状态。
