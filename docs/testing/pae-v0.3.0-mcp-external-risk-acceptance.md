## 二、风险现象

非法或严重不完整 HTML 提交后，MasterGo MCP 返回成功并生成残缺画布：

- **输入**：含 16 类异常的 HTML（未闭合标签、非法标签、属性值不平衡尖括号、缺失引号闭合、标签交叉闭合等）；
- **MCP 行为**：`submit_page_to_canvas` 返回 `"✅ 设计稿生成已成功完成"`，无错误、警告或部分执行说明；
- **画布结果**：MasterGo 实际画布产生了 3 个大面积空白、仅保留顶部残缺内容的页面（`PAE-TC054R-Invalid-HTML` / `PAE-TC054R-Invalid-HTML-Structure` / `PAE-TC054R-Invalid-HTML-Structure-Unclosed-1`）及对应图层（含 `top-nav-unclosed-1` 等）；
- **风险特征**：残缺页面具有正常页面外框、页面标题和图层结构，存在被误认为正式成果的风险。

## 四、责任归属分析

| 事实 | 归属 |
|---|---|
| 异常 HTML 通过 `submit_page_to_canvas` 提交，MCP 返回成功 | MasterGo MCP 客户端行为 |
| 实际画布产生 3 个大面积空白残缺页面，含正常外框、页面标题和图层结构 | MasterGo MCP HTML 转换行为（缺少结构性校验与部分执行反馈） |
| 残缺页面存在被误认为正式成果的风险 | MasterGo MCP 转换结果与失败响应能力边界 |
| PAE v0.3.0 业务代码中无任何直接调用 MasterGo MCP 的代码 | PAE 不直接产生残缺画布 |
| `mastergo-result.json` 仍为 `status: "pending"`，未被 MCP 回写 | 与 v0.3.0 能力边界一致 |

**结论**：当前所有证据指向 **MasterGo MCP 输入校验和 HTML 转换能力边界**，尚未证明属于 PAE v0.3.0 业务代码缺陷。

## 五、PAE v0.3.0 产品边界

### 5.1 PAE 负责范围

| 责任项 | 说明 |
|---|---|
| 生成符合规范的 HTML 成果物 | PAE 通过 Prototype DSL 和原型生成代码，生成结构完整、格式规范的 HTML |
| 数据产物层验证（C-08） | mastergo-data.json / mastergo-result.json / manifest.json 的完整性和一致性 |
| MCP 链路层验证（C-30） | 正常 HTML 通过 submit_page_to_canvas 创建画布的能力（TC-052 PASS） |
| 画布质量层验证（C-30） | 正常 HTML 生成画布的内容、布局和视觉质量（TC-053 PASS） |

### 5.2 PAE 不负责范围

| 责任项 | 说明 |
|---|---|
| 替代 MasterGo MCP 完成通用 HTML 语法校验 | v0.3.0 未承诺此能力；MCP 输入校验属于 MCP 自身职责 |
| 拦截用户任意构造的非法 HTML | 当前 PAE 不存在将用户任意构造的非法 HTML 自动提交至 MasterGo 的正式业务链路 |
| 处理 MCP 返回成功但实际生成残缺画布的场景 | 此为 MCP 能力边界，非 PAE 业务代码缺陷 |

### 5.3 正式业务链路验证

正常 PAE 产物链路已验证通过：

| 链路 | 验证用例 | 结果 |
|---|---|---|

| 画布内容、布局与视觉质量 | TC-053（C-30 画布质量层） | **PASS** |

## 七、最终处置方案

### 7.1 风险接受

**已接受为外部工具已知风险**：

- 当前证据明确指向 MasterGo MCP 能力边界，而非 PAE v0.3.0 业务代码缺陷；
- 正常 PAE 产物链路已验证通过，风险不影响核心功能；
- 风险场景为极端边界情况，非 PAE 正常使用流程。

### 7.2 后续增强项（不阻塞 v0.3.0）

建议在后续版本中考虑以下增强（作为产品优化项，不作为 v0.3.0 缺陷修复）：

| 增强项 | 说明 | 优先级 |
|---|---|---|
| PAE 提交前 HTML 结构校验 | 在 PAE ↔ MasterGo MCP 接入层增加 HTML 结构校验（基本闭合、标签白名单、属性合法性） | 中 |
| 输入 HTML 最小可用性检查 | 在调用 submit_page_to_canvas 前对输入 HTML 做最小可用性检查 | 中 |
| mastergo-result.json 记录本地校验状态 | 在 mastergo-result.json 中至少记录本地校验状态 | 低 |

## 九、明确禁止事项

以下行为**严格禁止**，无论风险是否被接受：

1. **禁止将 TC-054-R 改为 PASS**：FAIL 记录必须永久保留；

3. **禁止修改验收计划 PASS/FAIL 标准以掩盖风险**：验收标准必须保持原定义；
4. **禁止自动登记 PAE-030-016**：风险登记为 MCP-EXT-001，不占用 PAE-030 缺陷编号；
5. **禁止自行升级 C-30 状态或覆盖统计而不经用户确认**：C-30 升级为"已覆盖，附已接受外部风险"及覆盖统计升级为 30/30 必须基于用户明确确认；
