# PAE v1.6.0 迭代计划

## 版本主题

基于平台知识的跨模块复杂需求设计与变更管理。

## 第一批：平台模块图谱

- 建立独立的 `knowledge/platform/modules` 模块目录，不改变 v1.4.0 正式知识实体和晋升契约。
- 描述组织机构、权限、表单、流程和报表五个基础模块。
- 支持 data、permission、configuration、lifecycle、integration 五类依赖。
- 校验重复模块、未知依赖、自依赖、非法依赖类型和目录越界。
- 支持模块查看、列表和 Mermaid 依赖图输出。

## 后续批次

### 第二批：跨模块影响分析（已完成）

- 基于模块名称、职责、核心对象和扩展点识别直接影响模块。
- 根据模块依赖向上展开间接影响，并识别下游回归模块。
- 生成 JSON、Markdown 和 Mermaid 三类分析产物。
- 对平台增强、项目定制、架构评估和证据不足场景提供边界建议。
- 所有边界建议固定为待产品经理确认，不直接替代产品决策。
- 新增脱敏“跨模块数据权限控制”需求样例。

### 后续批次

1. 多方案比较和产品经理选择门禁；
2. 复杂需求设计单元及跨成果物追踪；
3. 需求变更检测和受影响单元增量重算；
4. 脱敏“跨模块数据权限控制”真实业务验收。

## 发布边界

第一批只建立 v1.6.0 技术基础，不代表版本完成或可以发布。合并、Tag 和 Release 必须在全部批次及保留人工验收边界确认后单独执行。
