# PAE v1.0.0 迭代计划

## 版本目标

v1.0.0 是 PAE 首个稳定可用版本，以 **One Prompt → One Product** 为目标，将已有成果生成、MasterGo、文档和正式交付能力收敛为可恢复、可追踪、可验收的统一链路。

## 迭代批次

| 批次 | 范围 | 完成条件 |
|---|---|---|
| 第一批 | Schema 1.0、`pae.config.json`、`run.json`、`run-events.jsonl` | 配置可校验；成功与失败运行均可追踪 |
| 第二批 | `pae deliver` 端到端编排 | 一个命令完成设计、文档和交付 |
| 第三批 | 幂等、续跑、重试与输入失效范围 | 中断后可恢复，重复执行不破坏成果 |
| 第四批 | `pae doctor`、release 质量门禁和交付总览 | 环境与成果问题可自动定位 |
| 第五批 | 双业务验收、历史兼容、发布文档 | 满足 v1.0.0 正式发布门槛 |

## 第一批契约决策

- 新增的稳定契约统一使用 `schemaVersion: "1.0"`。
- v0.9.0 既有成果物暂不强制迁移，避免第一批引入破坏性变更。
- 配置优先级为：CLI 参数 > `pae.config.json` > 环境变量/默认值。
- 每次工作流执行覆盖写入 `run.json`，并以 JSON Lines 追加同次运行的阶段事件。
- 状态枚举统一为 `PENDING`、`RUNNING`、`WAITING_CONFIRMATION`、`SUCCEEDED`、`FAILED`、`SKIPPED`、`STALE`。

## 第一批验收范围

1. 无配置文件时可加载安全默认值。
2. 非 1.0 配置或非法重试参数被拒绝。
3. 成功工作流生成完整运行状态和事件记录。
4. 阶段失败时准确记录失败原因，并将下游阶段标记为跳过。
5. v0.3.0—v0.9.0 既有自动化测试保持通过。
