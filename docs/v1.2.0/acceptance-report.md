## 4. 状态与安全验收

- 首次低代码需求运行状态为 `WAITING_CONFIRMATION`。
- 等待期间所有正式设计阶段保持 `PENDING`。
- `RUN_WAITING_CONFIRMATION` 事件可追踪。
- 人工确认与需求指纹及完整分析哈希绑定。
- 扩展或需求变化会改变运行指纹并阻止复用旧成果。
- 知识接受前保留人工审核门禁，更新前保存历史快照。
- 工作空间身份不一致、候选不存在和重复接受均被阻断。
