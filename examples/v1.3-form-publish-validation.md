# 表单发布前校验规则

## 背景

低代码平台的表单设计器允许产品实施人员配置字段、布局和基础校验。当前点击发布时只检查表单名称和数据表是否存在，部分配置错误需要到运行态才能发现。

## 用户问题

- 必填字段未配置可识别的字段名称时仍能发布。
- 下拉字段没有选项来源时仍能发布。
- 字段联动规则引用已删除字段时，发布阶段没有明确提示。
- 用户无法从错误信息快速定位到设计器中的具体字段。

## 目标

在表单发布前执行统一校验，阻断确定性配置错误，并将错误定位到字段或规则。暂不调整底层数据模型，不替代运行态业务校验。

## 初步范围

1. 发布前检查表单基本信息、字段配置和字段联动引用。
2. 错误按“阻断”和“提醒”分类展示。
3. 点击问题项可以定位到对应字段或规则。
4. 阻断错误全部解决后才允许发布。
5. 保持已发布历史表单可继续运行。

## 待确认

- 提醒类问题是否允许用户忽略并继续发布。
- 存量表单再次发布时是否使用全部新规则。
