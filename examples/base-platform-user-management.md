# 基础平台用户管理

## 目标

为基础平台建设统一的用户管理能力，支持管理员维护用户账号、组织与岗位关系，并清晰展示账号状态。

## 功能范围

- 用户列表支持按姓名、账号、手机号、所属组织、岗位和状态组合检索。
- 支持新增、编辑、查看用户，并将姓名、登录账号、所属组织设为必填项。
- 支持启用、停用和批量停用；停用属于危险操作，执行前必须二次确认并说明影响。
- 列表页与详情页均需展示启用、停用状态。
- 支持为用户关联多个岗位，但必须指定一个主岗位。
- 无权限、账号重复、组织失效或保存失败时，应提供明确反馈且不得提交脏数据。

## 权限

平台管理员可新增、编辑和启停用户；组织管理员仅可查看和维护授权组织范围内的用户；普通用户无管理入口。
